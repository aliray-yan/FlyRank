# FlyRank — Capstone Project

FlyRank is a capstone repository to demonstrate AI-assisted development workflows using VS Studio and GitHub Copilot.

## Status

Initial scaffolding and assistant rules are present. This repo is ready for iterative development.

## Goals

- Showcase AI-assisted development with GitHub Copilot and VS Studio
- Keep a clean history using Conventional Commits

## Quick start

1. Clone the repo
	 ```bash
	 git clone <your-remote-url>
	 cd FlyRank
	 ```
2. Open in VS Studio and enable GitHub Copilot for code suggestions.

## Installation (local)

- Install Node.js (LTS) from https://nodejs.org/
- Install project dependencies (if any):
	```bash
	npm install
	```

## Contributing / Commit guidelines

- Use Conventional Commits for all commits, e.g. `feat: add login flow`, `fix(api): handle 500`.
- Branches: `main` for production, `feature/*` for work-in-progress.
